# 0.0.2-preview 發布紀錄與相容性變更

2026-10-21，六個套件於 GitHub Packages 公開發布，並以 .NET SDK 8 與 10 完成安裝驗收。[套件發布](https://github.com/YuChia-Wei/ArchPrecept/actions/runs/39626267158)

## 發布成品

發布來源為 `a51bc09a7d68d0477788019b12c54b7e0b461982`。[v0.0.2-preview](https://github.com/YuChia-Wei/ArchPrecept/tree/v0.0.2-preview)

## 套件與升級

六個套件共用版號。Domain 及 Analyzer 可各自安裝。Messaging 提供共同的訊息契約，Application.Messaging 提供 Application 向外發布的 port。兩個訊息套件均不引入 Domain、Analyzer 或 Configuration。

## 相容性變更

下表比較自 `0.0.1-preview` 升級時受影響的公開及受保護 API。

| API／行為 | 0.0.1-preview | 0.0.2-preview | 遷移影響 |
|---|---|---|---|
| `EsAggregateRoot<TId>` | Domain assembly／namespace | Domain.EventSourcing assembly／namespace，仍繼承 AggregateRoot | 新增 PackageReference、調整 using、重新編譯；無 type forwarder |
| 歷史建構子 | `EsAggregateRoot(IEnumerable<IDomainEvent>)` 立即重播 | 移除；新增 `LoadFromHistory` | 衍生初始化完成後明確載入 |
| 一般建構子 | 受保護無參數建構子 | 保留；另提供 `EsAggregateRoot(TId)` | 既有無參數建立方式可保留 |
| Domain 三個事件 mutator | 非 virtual | virtual；一般 Domain 行為保留 | ES 的 sealed override 拒絕直接變更；通用清除流程需改用 commit |
| `Apply`／`When`／`GetLastDomainEvent` | 同名受保護方法 | 簽章保留 | 加入失敗實例與重入防護；失敗後丟棄實例 |
| `MarkChangesAsCommitted(int)` | 版本算術檢查後清除 | 簽章與成功語意保留，另拒絕失敗／轉換中實例 | 仍由 adapter 負責原子 append 與 expected revision |
| DBA1001–DBA1017 | 既有 17 個 Diagnostic | ID、severity、規則實作不變 | DBA1009 可辨識新 ES 組件 |
| `IIntegrationEvent`／`IRequestContract` | Messaging.Abstractions | Messaging | 成員保留，更新引用與 namespace |
| `IIntegrationEventPublisher`／`IntegrationMessageDelivery` | Messaging.Abstractions | Application.Messaging | overload／record 形狀及預設委派保留；不保證預設處理 metadata |
| `MessagingTransportOptions`／`MessagingTransportProfile` | 隨契約套件發布 | 移到不發布的 host 參考範例 | 消費端接管設定類別與 Configuration 相依 |

更換舊的 `Messaging.Abstractions` 套件參考後須重新編譯。使用組件或型別名稱做序列化識別時，另行處理映射。此版提供事件溯源與 Messaging 契約，儲存、投影與 broker 交付由採用端實作。[事件溯源契約](https://github.com/YuChia-Wei/ArchPrecept/blob/v0.0.2-preview/docs/product/event-sourcing-contract.md) · [Messaging 契約](https://github.com/YuChia-Wei/ArchPrecept/blob/v0.0.2-preview/docs/product/messaging-contract.md)
