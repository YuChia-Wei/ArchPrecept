## 版本建議

本版採 `0.0.2-preview`，先完成本機候選驗證，再依 DEC-019 公開發布。
`0.0.1-preview.2` 適合仍以 0.0.1 為目標的預覽修訂；此次增加可獨立安裝的套件，
移動公開型別並調整建構／重播與事件變更行為，另設 0.0.2 預覽基線較容易追蹤遷移。
這是產品在 0.x 初期的版本選擇，不是 SemVer 強制規則，也不表示 patch 向下相容。
兩種格式都合法；[SemVer §4／§9](https://semver.org/spec/v2.0.0.html) 允許初期 0.x API 變動，
且預覽版不保證穩定。正式版政策仍另行決定。

六個套件沿用共同 release train：`ArchPrecept.Contracts.Domain`、`ArchPrecept.Contracts.Application`、
`ArchPrecept.Contracts.Messaging`、`ArchPrecept.Contracts.Application.Messaging`、
`ArchPrecept.Contracts.Domain.EventSourcing` 與 `ArchPrecept.Analyzers.Core`。
只想使用一般 Domain／Analyzer 的消費端不需安裝 ES 或 Messaging。
已發布的 `0.0.1-preview` bytes 保持不變。

## 相容性變更

本次相容性比較範圍為 CT-004／CT-005 直接影響的公開／受保護 API，對照既有 `0.0.1-preview`
來源與本次候選；不是全產品二進位相容性認證。

| API／行為 | 0.0.1-preview | 0.0.2-preview 候選 | 遷移影響 |
|---|---|---|---|
| `EsAggregateRoot<TId>` | Domain assembly／namespace | Domain.EventSourcing assembly／namespace，仍繼承 AggregateRoot | 新增 PackageReference、調整 using、重新編譯；無 type forwarder |
| 歷史建構子 | `EsAggregateRoot(IEnumerable<IDomainEvent>)` 立即重播 | 移除；新增 `LoadFromHistory` | 衍生初始化完成後明確載入 |
| 一般建構子 | 受保護無參數建構子 | 保留；另提供 `EsAggregateRoot(TId)` | 既有無參數建立方式可保留 |
| Domain 三個事件 mutator | 非 virtual | virtual；一般 Domain 行為保留 | ES 的 sealed override 拒絕直接變更；通用清除流程需改用 commit |
| `Apply`／`When`／`GetLastDomainEvent` | 同名受保護方法 | 簽章保留 | 加入失敗實例與重入防護；失敗後丟棄實例 |
| `MarkChangesAsCommitted(int)` | 版本算術檢查後清除 | 簽章與成功語意保留，另拒絕失敗／轉換中實例 | 仍由 adapter 負責原子 append 與 expected revision |
| DBA1001–DBA1017 | 既有 17 個 Diagnostic | ID、severity、規則實作不變 | 套件 consumer 驗證新 ES assembly 仍可被 DBA1009 辨識 |
| `IIntegrationEvent`／`IRequestContract` | Messaging.Abstractions | Messaging | 成員保留，更新引用與 namespace |
| `IIntegrationEventPublisher`／`IntegrationMessageDelivery` | Messaging.Abstractions | Application.Messaging | overload／record 形狀及預設委派保留；不保證預設處理 metadata |
| `MessagingTransportOptions`／`MessagingTransportProfile` | 隨契約套件發布 | 移到不發布的 host 參考範例 | 消費端接管設定類別與 Configuration 相依 |

先前尚未發布的 `ArchPrecept.Contracts.EventSourcing` 候選名稱已統一為
`ArchPrecept.Contracts.Domain.EventSourcing`，包含測試專案、namespace、範例、封裝與 workflow。
舊 `Messaging.Abstractions` 不產生相容轉接套件。保留型別成員不代表 assembly／namespace 身分相容；
必須重新編譯，使用儲存型別名稱的序列化器另行處理映射。

沒有新增儲存 adapter、schema migration、snapshot、投影執行器或 Analyzer 規則。
