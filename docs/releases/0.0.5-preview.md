# 0.0.5-preview

2026-11-21 已發布至 GitHub Packages，七個 `0.0.5-preview` 套件均為 public 且連結至 ArchPrecept repository。新增的 `ArchPrecept.Templates` 提供 `ap-starter` 專案範本與 `ap-vo` 純量 Value Object 範本，與 Analyzer 和五個 Contracts 套件採共同版號。[發布與 registry 驗證紀錄](https://github.com/YuChia-Wei/ArchPrecept/actions/runs/44889494020)

依[範本使用指南](../templates.md)從 SDK 安裝成品、建立 starter、新增 Price，並在 reference 與 custom 兩種模式驗證 DBA1018。自有契約模式只引用 Analyzer。規則與公開 runtime 契約延續 [0.0.4-preview](0.0.4-preview.md)。

此次涵蓋 #24、#25 和 #26 的首個純量 VO。Aggregate、Domain Event、Application items 及 snippets 屬後續範圍。試用專案的採用結果會用來判斷核心功能是否完成；必要修正繼續以 `0.0.n-preview` 發布。核心功能確認且簡易官網完成後，再依 [#20](https://github.com/YuChia-Wei/ArchPrecept/issues/20) 確認版本政策及 0.1.0 準備度。見[後續發布路線](stable-release-roadmap.md)。

## 發布與驗收

GitHub Actions 從 main 提交 `9b27cf99868273957786062b62ba9e1986481b61` 建置並封裝。Analyzer 的 251 個測試及 Domain／EventSourcing 在 net8.0、net10.0 各 26 個測試通過。七個 nupkg 的 nuspec 均記錄此來源提交。

SDK 8.0.428 與 10.0.404 各自從 GitHub Packages 還原全部七個套件到獨立快取，來源與 SHA-256 均符合本次發布的成品。兩個 SDK 各自安裝範本，以 reference 及 custom 模式建立 starter 並新增 `Price`。四組皆在 `Price.Value` 加上公開 setter 後收到 DBA1018 建置錯誤，移除 setter 後重新建置成功。custom 模式的專案相依只包含 ArchPrecept 的 Analyzer。[SDK 8 驗收](https://github.com/YuChia-Wei/ArchPrecept/actions/runs/44889494020/job/136802824934) · [SDK 10 驗收](https://github.com/YuChia-Wei/ArchPrecept/actions/runs/44889494020/job/136802824846)
