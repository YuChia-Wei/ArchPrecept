# 0.0.5-preview

2026-11-21，七個套件於 GitHub Packages 公開發布，並以 .NET SDK 8 與 10 完成安裝驗收。[套件發布](https://github.com/YuChia-Wei/ArchPrecept/actions/runs/44889494020)

新增的 `ArchPrecept.Templates` 提供 `ap-starter` 專案範本與 `ap-vo` 純量 Value Object 範本，與 Analyzer 及五個 Contracts 套件共用版號。Starter 可採用參考契約或自有契約，自有契約模式只引用 Analyzer。規則與公開 runtime 契約沿用上一版。[範本使用指南](../templates.md) · [0.0.4-preview](0.0.4-preview.md)
