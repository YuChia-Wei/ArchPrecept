# 0.0.4-preview

狀態：**2026-11-02 已公開發布至 GitHub Packages，SDK 8／10 registry consumer 驗收通過**。nuget.org 另行準備；外部 lab 的採用結果與發布驗收分開判讀。

## 交付內容

相對 0.0.3-preview 的實際發布來源 `fdc1f9ff3934c769047f797803abc8614290e889`，本版交付 Repository 繼承與逐 port 泛型分析、明選 PureQuery 能力檢查、UseCase 有效入口、平台符號與 ES transition 精確辨識，以及 DomainEntity.Id 初始化防護。詳細差異、限制與舊版定位見[規則契約差異](rule-contract-candidate.md)。

六套件仍採共同版號，各自可以獨立安裝；Analyzer-only 與 custom-contract 保持支援。補充原生 API XML、使用指南及隨包規則文件；HelpLink 定位來源 SHA。

## 升級注意事項

更精確的角色、繼承及能力辨識可能新增原本漏掉的診斷，也會移除同名型別造成的誤報。請檢視診斷與適用政策，不以全面 suppression 隱藏升級差異。Id 未指派就讀取會擲出 InvalidOperationException，指派 null 會擲出 ArgumentNullException；0 或 Guid.Empty 的有效性仍由領域決定。

## 發布及驗證

[發布 run 41450634251](https://github.com/YuChia-Wei/ArchPrecept/actions/runs/41450634251) 由 `e16df4e0415c2a0ef50f7db64db13e70e542bd0e` 建置並上傳六套件。gate、package、SDK 8／10 local-feed consumer、publish、public metadata verification 與 SDK 8／10 registry consumer 全部成功。六包均為 public 並連結本 repository，registry 還原 hash 與同次發布 artifact 一致。

Analyzer 251 個測試、Domain／ES 在 net8.0 與 net10.0 各 26 個測試通過；SDK 8.0.427／10.0.403 的七種採用模式、19 條規則與 severity、mapping／Profile／設定及 Products HTTP／UseCase 每 SDK 5 個測試通過。發布前語意審查修正了 Messaging 範例缺少 OccurredOn 及當版狀態敘述；最終來源與受影響隨包文件已複查。

MQ／Web API lab 的實際採用結果見[consumer 驗證紀錄](0.0.4-consumer-validation.md)。沒有宣稱完整架構合規、真實 ORM／broker／交易保證。
