# 0.0.4-preview

2026-11-02，六個套件於 GitHub Packages 公開發布，並以 .NET SDK 8 與 10 完成安裝驗收。[套件發布](https://github.com/YuChia-Wei/ArchPrecept/actions/runs/41450634251)

## 交付內容

本版更新 Repository、角色辨識及公開 API 文件。與 [0.0.3-preview](0.0.3-preview.md) 相比，Diagnostic ID、Profile 與 severity 維持不變。

| 規則 | 變更 |
|---|---|
| DBA1001 | 分析有效繼承、逐 port 泛型替換，以及顯式或基底 adapter 實作。分離的 query port 不因多 port 聯集誤報。 |
| DBA1002／1010 | 依 BCL symbol、明確 service-locator mapping 與平台注入 attribute 辨識。 |
| DBA1003／1008 | 依實際型別歸責巢狀宣告。DBA1003 的訊息限辨識到的 DbContext 子集。 |
| DBA1004／1005／1006／1012 | 依有效 Controller attribute、持久化契約 API 與 override／實作鏈及 target-typed `new` 辨識。 |
| DBA1007／1013 | 精確辨識寫入 API，維持 static Mapper 及 query reader 禁止寫入的政策。 |
| DBA1009 | 允許 ES root 的 canonical virtual／abstract transition 及其 override 修改狀態。普通 `When`、lambda 和 local function 不適用此例外。 |
| DBA1014 | `PureQuery` 明選 Controller，且所有依賴的實際 view 須為唯讀查詢。混合介面及可寫入的 concrete adapter 均受檢查。 |
| DBA1015 | 辨識繼承、顯式實作及 override 的有效 `ExecuteAsync` 入口，並分開檢查 Input 形式與 transport 身分。 |
| DBA1011／1016／1017 | Command 可回傳結果。DBA1016 涵蓋欄位、屬性、方法參數、呼叫及 Application 自有 ports。DBA1017 納入欄位、屬性的相異依賴型別計數。 |
| DBA1018／1019 | 維持 VO 可變狀態與 Entity 參考的嚴格政策，並沿用 `ddd` opt-in 與 Warning。 |

六個套件共用版號，各自可以獨立安裝。Analyzer 支援使用自有契約。本版補充 API XML、使用指南及隨包規則文件，HelpLink 定位到封裝時的來源修訂。[本版 Diagnostic 手冊](https://github.com/YuChia-Wei/ArchPrecept/tree/v0.0.4-preview/docs/diagnostics)

## 升級注意事項

更精確的角色、繼承及能力辨識可能新增原本漏掉的診斷，也會移除同名型別造成的誤報。請檢視診斷與適用政策，不以全面 suppression 隱藏升級差異。Id 未指派就讀取會擲出 InvalidOperationException，指派 null 會擲出 ArgumentNullException；0 或 Guid.Empty 的有效性仍由領域決定。
