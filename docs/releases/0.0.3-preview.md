# 0.0.3-preview

本版承接 #6、#7、#8、#11、#1、#9；使用者於 2026-10-22 核准所有不依賴 Framework 安裝的核心工作與 0.0.3-preview 發布。Framework 採納草案與等待 0.21.0 正式發布的決定保存於 [.dev/planning](../../.dev/planning/README.md)。

## 交付內容

- 六套件責任與相依方向維持不變，Contracts API 不新增 runtime framework 相依。
- 共用角色分類、完整內建 metadata／組件身分、明確自有 mapping、繼承／泛型限制與低信心命名證據。
- 可選 core／web-api／messaging／event-sourcing／framework／ddd Profile，兩層設定與單一規則覆寫；無效設定 DBA0001、明確範圍狀態 DBA0002。
- 修正 DBA1016 對真正程序內領域事件 dispatcher port 的誤報，保留 bus／transport 混入的禁止相依。
- DBA1018 檢查 VO 可變狀態，DBA1019 檢查 Entity 參考；ddd opt-in、Warning 預設，不宣稱 deep immutability。
- 唯一 Rule Catalog 與 Schema、Descriptor HelpLink、更新的繁中手冊與無 AI 安裝／檢核入口。
- Products 建立／讀取 Web API、程序內 adapter、HTTP／UseCase 測試及隔離的違規／修正案例；以實際 nupkg 執行。

## 升級與界線

未設定時保留 legacy 的既有 17 條規則與 severity。中央分類器可辨識先前漏掉的繼承、record／struct、自有 mapping；這些有效角色可能新增診斷。使用明確 Profile／mapping 是採用政策選擇；名稱證據不等同精確契約。

Contracts-only／Analyzer-only 仍可分開採用。#5 的另一採用端升級不由本版自行執行；#10 的 P2 跨 Project 測試仍未交付。完整 Conformance CLI、完整架構合格判定、其他 OS matrix 與 nuget.org 不在本次範圍。
