# ArchPrecept 0.1.0-preview.1

此版本是首個正式版 0.1.0 的預覽候選，包含七個共用版號的套件。發布目標為 NuGet.org 與 GitHub Packages。各平台的可下載狀態與 SDK 8／10 安裝驗收尚待確認。

## 與 0.0.6-preview 的差異

- 組件邊界測試範本支援以 `--namespace` 指定測試類別的命名空間，並為產生的公開類別與方法提供 XML 說明。[架構測試](../architecture-testing.md)
- 安裝指南新增最小 Analyzer 使用範例與診斷驗證步驟。Event Sourcing 文件補充沿用既有事件型別、重播歷史，以及提交後分派事件的遷移範例。[安裝指南](../getting-started.md) · [Event Sourcing 契約](../product/event-sourcing-contract.md)

## 取得套件

NuGet.org 上架後可匿名還原。使用 GitHub Packages 時需要可讀取套件的憑證，來源為 `https://nuget.pkg.github.com/YuChia-Wei/index.json`。測試特定平台時請將 ArchPrecept 的套件來源限定為該平台。

```sh
dotnet add package ArchPrecept.Analyzers.Core --version 0.1.0-preview.1
dotnet new install ArchPrecept.Templates::0.1.0-preview.1
```
