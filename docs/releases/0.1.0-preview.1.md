# ArchPrecept 0.1.0-preview.1

七個共用版號的套件已發布至 NuGet.org 與 GitHub Packages。兩個來源均以 .NET SDK 8 與 10 完成套件使用驗收。`0.1.0-preview.1` 是預覽版，首個正式版 `0.1.0` 尚未發布。[NuGet.org 發布與匿名還原驗收](https://github.com/YuChia-Wei/ArchPrecept/actions/runs/46105981588) · [GitHub Packages 發布與還原驗收](https://github.com/YuChia-Wei/ArchPrecept/actions/runs/46105981552) · [發布來源 v0.1.0-preview.1](https://github.com/YuChia-Wei/ArchPrecept/tree/v0.1.0-preview.1)

## 與 0.0.6-preview 的差異

- 組件邊界測試範本支援以 `--namespace` 指定測試類別的命名空間，並為產生的公開類別與方法提供 XML 說明。[架構測試](../architecture-testing.md)
- 安裝指南新增最小 Analyzer 使用範例與診斷驗證步驟。Event Sourcing 文件補充沿用既有事件型別、重播歷史，以及提交後分派事件的遷移範例。[安裝指南](../getting-started.md) · [Event Sourcing 契約](../product/event-sourcing-contract.md)

## 取得套件

NuGet.org 使用公開來源 `https://api.nuget.org/v3/index.json`，可匿名還原。七個套件的 NuGet.org Owner 均為 [ArchPrecept](https://www.nuget.org/profiles/ArchPrecept)。以下命令安裝 Analyzer 與 SDK 範本。依需要選用其他套件時，請一併指定 `0.1.0-preview.1`。[七個套件及必要相依](../getting-started.md#1-選擇套件)

```sh
dotnet add package ArchPrecept.Analyzers.Core --version 0.1.0-preview.1
dotnet new install ArchPrecept.Templates::0.1.0-preview.1
```

GitHub Packages 的來源為 `https://nuget.pkg.github.com/YuChia-Wei/index.json`。本機使用有套件讀取權限的 GitHub 憑證，Actions 可使用有權限的 `GITHUB_TOKEN`。使用 source mapping 的專案請將 `ArchPrecept.*` 對應到選用的來源。[GitHub NuGet registry 驗證說明](https://docs.github.com/en/packages/working-with-a-github-packages-registry/working-with-the-nuget-registry)
