# DBA1003：Aggregate 不應相依基礎設施型別

## 目的與預設嚴重性

此規則避免 Aggregate 或 Entity 直接引用 `DbContext` 型別，讓 Domain 模型維持與持久化基礎設施分離。

| 項目 | 值 |
| --- | --- |
| Diagnostic ID | `DBA1003` |
| Descriptor 標題 | `Aggregate should not depend on infrastructure types` |
| 類別 | `Architecture` |
| 預設嚴重性 | `warning` |
| 預設啟用 | 是 |

## 適用範圍與觸發條件

分析器只分析 C# `class` 宣告，且不分析產生的程式碼。下列 class 會被視為 Aggregate／Entity 候選者：

- class 名稱以 `Aggregate`、`AggregateRoot` 或 `Entity` 結尾；或
- 任一基底類別名稱剛好為 `AggregateRoot` 或 `Entity`，或以 `AggregateRoot` 結尾。

對每個候選 class，分析器掃描其所有後代節點中的 `TypeSyntax`。若該型別的完整語意顯示名稱以 `.DbContext` 或 `DbContext` 結尾，就會對該型別出現位置回報 `DBA1003`。因此 `Microsoft.EntityFrameworkCore.DbContext`、衍生的 `AppDbContext`，甚至僅名稱以 `DbContext` 結尾的自訂型別，都屬於現行偵測範圍。

## 違規範例

```csharp
using Microsoft.EntityFrameworkCore;

public sealed class OrderAggregate
{
    private readonly DbContext dbContext;

    public OrderAggregate(DbContext dbContext)
    {
        this.dbContext = dbContext;
    }
}
```

欄位與建構式參數都是候選 class 內的型別使用；各出現位置都可能產生 `DBA1003`。

## 合規範例

```csharp
public sealed class OrderAggregate
{
    public OrderAggregate(string id)
    {
        Id = id;
    }

    public string Id { get; }
}

// DbContext 應位於 Repository 或其他 Infrastructure 實作中，
// 而不是 Aggregate 內。
```

## 修正指引

1. 從 Aggregate／Entity 的欄位、屬性、建構式與方法簽章移除 `DbContext` 與其衍生型別。
2. 將查詢、追蹤、交易與持久化工作移至 Infrastructure Repository、Unit of Work 或 Application Use Case。
3. Aggregate 只接收值、值物件與領域抽象所需資料；需要外部資料時，先在 Application 層取得並以明確輸入傳入。
4. 若因框架模型需要保留基礎設施型別，先確認此 class 是否真的是 Domain Aggregate；不要只靠 suppression 掩蓋責任混合。

## 已知限制與例外

- 角色與禁用型別都以名稱／後綴判定，不驗證 namespace 或實際是否繼承 EF Core 的 `DbContext`。這可能造成同名型別的誤報，也可能漏掉名稱不含 `DbContext` 的其他基礎設施相依。
- 規則掃描 `TypeSyntax`，不做資料流、反射或執行期 DI 分析；它不是所有 Infrastructure 相依的完整檢查器。
- 只註冊 `class` 宣告，未分析 interface、struct、record declaration 或非 class 型別；巢狀 class 的型別語法仍位於外層 class 的後代節點掃描範圍內。
- 沒有 attribute、namespace 或設定可做自動豁免，也沒有 code fix。對已知且暫時無法重構的框架限制，使用最小範圍 suppression 並紀錄原因。
- 目前測試只覆蓋 `DbContext` 引用的違規案例，尚無本規則專屬的合規反例測試。

## 設定與 Suppression

目前沒有規則專屬設定鍵。預設範本將此規則設定為 `warning`：

```editorconfig
[*.cs]
dotnet_diagnostic.DBA1003.severity = warning
```

需要過渡性例外時：

```csharp
#pragma warning disable DBA1003 // 已記錄的框架過渡限制；追蹤項目：<id>
public sealed class LegacyAggregate { }
#pragma warning restore DBA1003
```

可用值為 `none`、`silent`、`suggestion`、`warning`、`error`。若調高為 `error`，請先以實際採用端確認名稱式判定不會擴大成未預期的阻擋。
