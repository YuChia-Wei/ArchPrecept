# DBA1018：ValueObject 不得包含可變狀態

## 目的與預設嚴重性

明確選用 ddd Profile 後，檢查 VO 的 instance 狀態不變意圖。預設 Warning；legacy 預設不啟用這條新增規則。

## 適用範圍與觸發條件

VO 必須由真正 IValueObject／ValueObject 或明確自有 mapping 辨識；單純同名不算。一般 setter（包含 private／protected）、非 readonly field、陣列或已知可變集合命中。init 本身允許，但仍檢查型別。繼承成員會納入；同一被辨識來源基底已處理的成員不在衍生型別重複診斷。

共同設定、權威與角色優先序見 [Analyzer 採用政策](../product/analyzer-policy.md)。

## 違規範例

```csharp
using ArchPrecept.Contracts.Domain;
public sealed class Price : IValueObject
{
    public decimal Amount { get; private set; }
}
```

## 合規範例

```csharp
using ArchPrecept.Contracts.Domain;
public readonly record struct Price(decimal Amount) : IValueObject;
```

## 修正指引

移除一般 setter，以 constructor 或 init 初始化純量；欄位使用 readonly，集合使用符合需求的不可變結構，且檢查元素型別。不要把 getter-only List<T> 誤認為 immutable。

## 已知限制與例外

不是 deep immutability 證明；object／dynamic、未知 metadata reference type、無約束泛型、循環或深度 16 上限以 DBA0002 回報未評估。已知不可變集合仍檢查元素；read-only collection interface 不證明其 backing state 不可變。靜態成員、方法副作用、反射及 runtime alias 行為不在此 instance 宣告範圍。generated code 排除。

## 設定與 Suppression

