# DBA1013：Projection 不應執行持久化寫入

## 目的與預設嚴重性

- **Diagnostic ID**：<code>DBA1013</code>
- **標題**：Projection should not perform persistence writes
- **預設 severity**：<code>Warning</code>（預設啟用）

Projection 是讀取端 Port；它不應直接寫入持久化層。將寫入移出 Projection，可保持讀寫責任分離並降低讀模型更新帶來的副作用。

## 適用範圍與觸發條件

### 適用範圍

規則分析 C# 的方法呼叫運算式。只有目前包含呼叫的型別實作了簡單名稱為 <code>IProjection</code> 的介面時，才會繼續檢查；產生程式碼不在範圍內。

### 精確觸發條件

在適用型別中，呼叫的目標方法符合下列任一情況時，會在呼叫運算式位置回報 <code>DBA1013</code>：

1. 方法名為 <code>SaveChanges</code> 或 <code>SaveChangesAsync</code>，且宣告該方法的型別繼承鏈含有名稱為 <code>DbContext</code> 的型別。
2. 方法名為 <code>Add</code>、<code>AddAsync</code>、<code>Update</code> 或 <code>Remove</code>，且宣告該方法的型別繼承鏈含有名稱為 <code>DbContext</code> 或 <code>DbSet</code> 的型別。

型別與介面均以簡單名稱辨識，不驗證命名空間或是否為 Entity Framework Core 的實際型別。

## 違規範例

~~~csharp
public interface IProjection
{
}

public class DbContext
{
    public void SaveChanges()
    {
    }
}

public sealed class OrderProjection : IProjection
{
    private readonly DbContext dbContext = new();

    public void Execute()
    {
        dbContext.SaveChanges(); // DBA1013
    }
}
~~~

## 合規範例

~~~csharp
using System.Collections.Generic;

public interface IProjection
{
}

public sealed class OrderProjection : IProjection
{
    public void Execute(List<object> results, object item)
    {
        results.Add(item);
    }
}
~~~

<code>List&lt;T&gt;.Add</code> 的宣告型別不是 <code>DbContext</code> 或 <code>DbSet</code>，所以不會觸發。

## 修正指引

1. 從 Projection 移除 <code>SaveChanges</code>、<code>Add</code>、<code>Update</code>、<code>Remove</code> 等持久化寫入。
2. 將需要寫入的責任放入 Command、Use Case、Repository 或明確的寫入端處理流程。
3. 若 Projection 只需建構回應資料，改用記憶體集合、純 DTO 轉換或由呼叫端管理查詢結果。
4. 保留 Projection 的輸入與輸出為讀取端資料，不以 Projection 兼任投影更新或交易提交。

## 已知限制與例外

- <code>IProjection</code>、<code>DbContext</code> 與 <code>DbSet</code> 皆只按簡單名稱判斷；同名自訂型別可能造成誤報，非同名的自訂持久化型別則不會被偵測。
- 規則只涵蓋 <code>SaveChanges</code>、<code>SaveChangesAsync</code>、<code>Add</code>、<code>AddAsync</code>、<code>Update</code> 與 <code>Remove</code>；例如批次、原生 SQL、包裝方法或其他寫入 API 不在目前偵測範圍內。
- 只有被語意模型解析為目標方法的直接呼叫會回報；規則不追蹤跨方法呼叫鏈。
- 不實作 <code>IProjection</code> 的服務即使呼叫同樣的持久化寫入方法，也不會由此規則回報。

## 設定與 Suppression

目前沒有 <code>DBA1013</code> 專屬設定。可在 <code>.editorconfig</code> 將其調整為更嚴格的 severity：

~~~ini
[*.cs]
dotnet_diagnostic.DBA1013.severity = error
~~~

若歷史投影在短期內必須維持寫入，suppression 應緊貼呼叫點並說明拆分計畫：

~~~csharp
#pragma warning disable DBA1013 // 舊投影遷移中；拆分寫入端後移除。
dbContext.SaveChanges();
#pragma warning restore DBA1013
~~~

廣域停用會讓所有 Projection 寫入失去檢查，僅應在有明確治理理由時使用：

~~~xml
<PropertyGroup>
  <NoWarn>$(NoWarn);DBA1013</NoWarn>
</PropertyGroup>
~~~
