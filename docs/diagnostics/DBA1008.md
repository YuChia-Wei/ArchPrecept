# DBA1008：Mapper 不應相依應用或持久化服務

## 目的與預設嚴重性

- **Diagnostic ID**：<code>DBA1008</code>
- **標題**：Mapper should not depend on application or persistence services
- **預設 severity**：<code>Warning</code>（預設啟用）

Mapper 應只進行物件或資料形狀的轉換。Repository、Use Case 與 Handler 相依會讓轉換器取得應用流程或持久化責任，降低可預測性與可重用性。

## 適用範圍與觸發條件

### 適用範圍

規則只分析名稱以區分大小寫的 <code>Mapper</code> 結尾的 C# 類別，並掃描該類別內所有後代 <code>TypeSyntax</code>。產生程式碼不在分析範圍內。

### 精確觸發條件

對每一個被解析出的型別語法，若其型別名稱符合下列任一個區分大小寫的後綴，會在該型別語法位置回報 <code>DBA1008</code>：

- <code>Repository</code>
- <code>UseCase</code>
- <code>Handler</code>

泛型型別以其未建構的型別名稱判斷；因此 <code>IOrderRepository</code> 與名稱為 <code>Repository&lt;T&gt;</code> 的型別都可能符合。

## 違規範例

~~~csharp
public sealed record Order(string Id);
public sealed record OrderDto(string Id);

public interface IOrderRepository
{
    Order Find(string id);
}

public static class OrderMapper
{
    public static OrderDto ToDto(Order order, IOrderRepository repository)
        => new(order.Id);
}
~~~

參數型別 <code>IOrderRepository</code> 以 <code>Repository</code> 結尾，因此會回報 <code>DBA1008</code>。

## 合規範例

~~~csharp
public static class OrderMapper
{
    public static OrderDto ToDto(Order order)
        => new(order.Id);
}
~~~

呼叫端應先完成查詢或協調，再把 Mapper 所需的資料傳入。

## 修正指引

1. 在 Use Case、Handler 或其他應用服務中取得資料並做流程協調。
2. 將 Mapper 縮小為只接受來源物件、值物件或明確的轉換資料。
3. 移除 Mapper 的 Repository、Use Case 或 Handler 型別欄位、屬性、方法參數、回傳型別與泛型型別引數。
4. 同時確認類別符合 <code>DBA1007</code> 的 <code>static</code> 要求。

## 已知限制與例外

- 這是名稱後綴規則，未驗證命名空間、實際服務角色或資料流；無關的型別只要名稱以這些後綴結尾，也可能被回報。
- 相反地，實際承擔 Repository、Use Case 或 Handler 職責但未使用這些名稱後綴的型別不會被此規則辨識。
- 規則只掃描型別語法，無法判斷執行階段解析、反射或其他未直接寫成型別語法的相依。
- 每一個符合條件的型別語法都可各自產生一筆診斷。

## 設定與 Suppression

目前沒有 <code>DBA1008</code> 專屬設定；可在 <code>.editorconfig</code> 調整通用 Roslyn severity：

~~~ini
[*.cs]
dotnet_diagnostic.DBA1008.severity = error
~~~

僅在確有已審查的過渡例外時，以局部 suppression 表達原因：

~~~csharp
#pragma warning disable DBA1008 // 遷移期間的相容層；移除期限：...
public static class LegacyOrderMapper
{
}
#pragma warning restore DBA1008
~~~

專案層級停用的做法如下，但會影響所有檔案，通常不應作為一般修正方式：

~~~xml
<PropertyGroup>
  <NoWarn>$(NoWarn);DBA1008</NoWarn>
</PropertyGroup>
~~~
